# Project brief: Example task management SaaS

Implement an MVP with workspaces, user sign-in, task CRUD, and a task board.
Reuse the existing repository framework and conventions. Do not replace the stack.

## Constraints
- Backend API and frontend must be covered by relevant tests.
- No production deployment in the initial phase.
- Keep task boundaries small (prefer one PR per task).
- Do not use paid services without explicit approval.

## Definition of Done
- Every task has measurable acceptance criteria.
- All required checks pass.
- Human reviewer approves and merges the PR.
